# ДЗ 1. Консольное меню

Программа на Node.js с меню из трёх задач. Ввод читается через `readline`.

## Запуск

```bash
node "ДЗ 1/homework-1.js"
```

## Задачи

1. **Билетная касса** — по категории билета (1, 2, 3) и бюджету считает, сколько билетов можно купить.
2. **Доставка заказа** — по расстоянию и сумме заказа считает стоимость доставки.
3. **Лестница** — печатает ступени, пропуская четвёртую и останавливаясь после десятой.

Если выбран пункт меню, которого нет, программа печатает `такой задачи нет` и завершается.

## Пример

```
Выберите задачу:
1 — билетная касса
2 — доставка заказа
3 — лестница
Ваш выбор: 2
Расстояние: 12
Сумма заказа: 2500
Расстояние 12 км, заказ 2500 руб.: доставка 250 руб.
```
